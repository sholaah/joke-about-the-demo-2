## What it does

`main.ts` (Node 22, stdlib only, no network) writes a single one-line joke
about working beside AI coding agents to `/output/entry.txt`. The text is
UTF-8, one line, and 1–280 characters counted as Unicode code points.

## The joke

> My AI coding agent is so fast that during the demo it fixed the bug, shipped two new ones, and blamed me — in the commit message.

## Run

```sh
node main.ts
cat /output/entry.txt
```
